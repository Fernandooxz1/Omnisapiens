¿Cómo probar estos botones en tu PC sin instalar nada?

En React o Angular necesitás Node.js porque el navegador no entiende archivos `.jsx` o `.ts` directamente. Pero si ponés el HTML y el CSS juntos en un archivo `.html` tradicional, **podés abrirlo con doble clic en Chrome, Edge o Firefox sin levantar ningún servidor**.

Paso 1

Copiá el código de acá abajo tocando el botón verde.

Paso 2

Pegalo en el Bloc de Notas o VS Code y guardalo como botones.html.

Paso 3

¡Hacé doble clic sobre el archivo y probalo directo en tu navegador!
